# Informe Técnico: descarga para GDE

Se movió la descarga DOCX para GDE desde la revisión del informe a la gestión
técnica posterior a la validación legal. La descarga ahora exige técnico de la
dupla activa y un informe validado; la carga manual de número IF y archivo GDE
no se modifica ni depende de la descarga.

El DOCX exportado justifica el estilo base para evitar que el cuerpo sin
alineación explícita quede alineado a la izquierda, preservando las
alineaciones explícitas existentes.
