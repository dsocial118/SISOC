# Experiencia de versiones de templates

Cada template utiliza una única versión en preparación. Guardar cambios sobre
esa versión no crea nuevas versiones; el gestor permite continuar editándola,
publicarla o descartarla.

El historial muestra únicamente versiones cerradas. Una versión histórica puede
usarse como punto de partida para crear una nueva versión en preparación, sin
modificar el contenido histórico.
