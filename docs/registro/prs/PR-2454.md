## Resumen operativo

- Tipo de cambio: fix
- Área principal: Usuarios / permisos PWA y SISOC Mobile
- Contexto funcional: El alta y edición de usuarios trataban el acceso a SISOC Mobile y el rol Coordinador de Equipo Técnico PWA como excluyentes. Al suspender el acceso mobile podían perderse las selecciones de permisos y ámbitos al guardar.
- Resumen para changelog: Conserva la configuración de permisos mobile al suspender el acceso y permite asignar el coordinador PWA sin borrar el acceso mobile.
- Impacto usuario: Los permisos secundarios mobile se ocultan cuando se deshabilita el acceso mobile, conservan su valor después de guardar y reabrir, y se restauran al habilitarlo otra vez. El rol Coordinador de Equipo Técnico queda limitado a la PWA y puede asignarse también al editar un usuario existente.
